# 遏云歌 CNOAT ACADEMY

虚拟网络课程宣传展示站（纯静态、单文件 HTML，无后端）。

## 页面特性

- 黑白配色 + 全页炫彩 3D 星空背景，鼠标移动有跟随光点与星光尾迹，点击迸发星光冲击波
- 板块：作品展示 + 关于我们 + 联系我们（微信二维码 / 邮件）
- 响应式适配桌面与移动端
- 页面组件灵感源自 [uiverse.io/galaxy](https://github.com/uiverse-io/galaxy)（MIT 协议）

## 文件结构

```
index.html                # 主页面（单文件，内联 CSS/JS；建站平台默认首页）
assets/                   # 运行依赖：6 张课程卡通插画 + 微信二维码
```

## 本地打开

直接用浏览器打开 `index.html`，或在 VSCode 中安装 Live Server 插件后右键“Open with Live Server”。
